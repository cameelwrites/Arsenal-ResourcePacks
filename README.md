# Resource Packs for Arsenal
A list of custom resources you can apply to your Arsenal for some extra chaos.  

| Resource |   |
| -------- | -------- |
| Deagle A2 | Replaces the Deagle animations with their A2 counterparts |
| Gangnam Style | Replaces the Parker Pride emote with a custom Gangnam Style Emote |
| Griddy | Replaces the Cranium Crowd emote with a custom Griddy Emote |
| Spidra Monky | Replaces the Spidra skin with the Monky Skin |
| Baby Pear | Replaces the Candles Weapon Skin with Baby Pear |
| Legacy Sounds | Restores some of the classic miscellaneous sounds |
| Legacy Gun Sounds **[BETA]**  | Attempts to restore early 2021 gun sounds |

### You can check out Fleasion here: https://github.com/fleasion/Fleasion  

# How To Install
1. Install/Open Fleasion
2. Go to the "Replacer" category
3. Press "Open Configs"
4. Drag and drop any resource config into that folder
5. Go to the configuration at the top and click the dropdown next to "Enabled"
6. Ensure your resources of choice are enabled then join a game
