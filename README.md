# How To Install
1. Install/Open Fleasion
2. Go to the "Replacer" category
3. Press "Open Configs"
4. Drag and drop any resource config into that folder
5. Go to the configuration at the top and click the dropdown next to "Enabled"
6. Ensure your resources of choice are enabled then join a game
