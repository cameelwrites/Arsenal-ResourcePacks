# Resource Packs for Arsenal
A list of custom resources you can apply to your Arsenal for some extra chaos via Fleasion. This does not add new content into the game only replaces the resources of existing content, in each resource folder there is a README that will tell you what is being replaced.  

**WARNING: Due to the way Fleasion works, there may be unintended side effects such as missing assets or incorrect assets. Additionally I can't guarantee the safety of using Fleasion, in my experience it is safe and shouldn't get you banned but it is best if you do your own research.**

### You can check out Fleasion here: https://github.com/fleasion/Fleasion  

# How To Install
1. Install/Open Fleasion
2. Go to the "Replacer" category
3. Press "Open Configs"
4. Drag and drop any resource config into that folder
5. Go to the configuration at the top and click the dropdown next to "Enabled"
6. Ensure your resources of choice are enabled then join a game
